# 使い方
## 1. 歌わせ方
歌わせるにはノートを追加します。まず、ピアノロール上部の「ツール」からペンを選択（もしくはショートカット 2）します。  
ピアノロールの好きな場所でクリックするとそこにノートが追加されます。ツールで「選択」または「ペン」を選んだ状態でノートを移動でき、ノートの右端の掴むとノートの長さを変更できます。  
ノートの移動と長さの変更はグリッドの沿ってクオンタイズされます。グリッドの幅はピアノロール上部の「グリッド」から変更できます。  
追加したノートを削除したい場合は「ツール」で選択を選んだ状態でノートを選択し、Deleteキーを押すか、「ツール」から消しゴム（ショートカット 3）を選んだ状態でノートをクリックします。  
ノートを追加したら歌詞を入力します。歌詞は、ノートをダブルクリックするか、左上の「歌詞を編集」から入力できます。  
歌わせるにはシンガーを選ぶ必要があります。シンガーは左上のシンガー設定から選ぶことができます。
